# Décisions d'architecture

Ce dossier conserve les choix durables qui influencent plusieurs composants ou imposent une migration. Une décision décrit le périmètre, les faits, les options, le choix, les conséquences et le signal de réexamen.

## Index

- [`0001-ai-foundation-alignment.md`](0001-ai-foundation-alignment.md) : adapter les principes AI Foundation sans dupliquer son contenu.

Les décisions sont immuables dans leur intention. Un choix remplacé reçoit le statut `deprecated` et une nouvelle décision décrit son successeur.

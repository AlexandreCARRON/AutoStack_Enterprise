# Documentation AutoStack Enterprise

Cette documentation décrit le catalogue de services versionnés et le générateur Docker Compose.

- [Architecture du dépôt](architecture.md) : organisation des services, variantes et fichiers générés.
- [Déploiement](deployment.md) : sélection d'une version, génération, validation et démarrage.
- [Migrations](migrations.md) : précautions pour les changements de versions majeures et les données persistantes.
- [Gouvernance](governance.md) : règles de maintenance, niveaux de revue et validations du dépôt.
- [Décisions d'architecture](../decisions/README.md) : choix durables, options et signaux de réexamen.
- [Contribution](../CONTRIBUTING.md) : flux de travail et contrôles locaux.
- [Sécurité](../SECURITY.md) : signalement privé et responsabilités de déploiement.
- [Catalogue des versions](../VERSIONS.md) : variantes disponibles, valeurs par défaut et références officielles.

Les exemples supposent que les commandes sont exécutées depuis la racine du dépôt.
